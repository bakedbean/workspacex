Run `wsx --help` for the full command list, or `wsx <command> --help` (e.g. `wsx agent --help`) for a group's commands and arguments. `wsx --version` prints the version.

```
wsx
```

Running with no arguments opens the dashboard.

A few command families live in their feature sections rather than here:

- `wsx agent list | send | add | remove` — see [Multi-agent workspaces](../agents/multi-agent-workspaces.md)
- `wsx status show` — see [Per-agent status](../agents/multi-agent-workspaces.md#per-agent-status)
- `wsx config get | set | list | edit <key>` — see [Global settings](../configuration/settings.md)
- `wsx remote [<name>]` — see [Named remote shortcuts](../integrations/remote-access.md)
- `wsx repo set-setup | set-archive | edit-setup | edit-archive <repo>` — see [Per-repo setup scripts](../configuration/setup-scripts.md)
- `wsx setup install-skill` — see [Agent skill](../agents/skills.md)
