# Integrations

wsx hands work off to the tools around it: your editor, terminal and difftool, agents running inside your editor, other repos, other machines, and your desktop bar.

- [Editor, terminal, and diff](editor-terminal-diff.md): open a workspace in your own tools with `e`, `t`, `v` and `g`.
- [Editor-hosted agents](editor-agent-context.md): give an agent in your editor the workspace's context.
- [Related repos](related-repos.md): let a workspace's agent read sibling repos.
- [MCP server inheritance](mcp-inheritance.md): reuse the source repo's MCP servers in every workspace.
- [Remote access](remote-access.md): reach wsx and its agents from another machine or your phone.
- [Shared workspaces](shared-workspaces.md): run agents in tmux so they outlive wsx and can be attached from anywhere.
- [Desktop widgets](desktop-widgets.md): show workspaces in Waybar, a KDE Plasma panel, or the macOS menu bar.
